# 🤖 AI Web Search Agent

An intelligent AI agent that answers user questions and retrieves real-time information from the web using tool-calling capabilities.

Built using modern **LLM agent architecture**, this project demonstrates how AI models can interact with external tools to provide more accurate and up-to-date answers.

---

## 🚀 Features

• AI-powered question answering  
• Real-time web search integration  
• Tool-calling agent architecture  
• Interactive chat interface  
• Lightweight and easy to run locally  

---

## 🧠 How It Works

1. User enters a question in the chat interface  
2. The AI agent analyzes the query  
3. If needed, it uses a web search tool  
4. The model processes the information  
5. The final response is returned to the user

---

## 🛠 Tech Stack

- Python  
- SmolAgents  
- Hugging Face Inference API  
- Gradio UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sashank23/ai-web-search-agent.git
```

Move into the project folder

```bash
cd ai-web-search-agent
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
python app.py
```

After running the script, a **Gradio chat interface** will open in your browser.
